Atlas v3
Cette version couvre 30 destinations, produit 10 hôtels sourcés par destination et par profil (couple/famille), affiche la date de mise à jour et publie 20 ouvertures hôtelières récentes ou annoncées.
Après dépôt des fichiers, lancer Update travel intelligence v3 dans GitHub Actions. La clé `OPENAI_API_KEY` reste inchangée.
Le workflow effectue une recherche importante. Les prix et disponibilités ne sont pas vérifiés ; les liens officiels et sources HTTPS sont conservés dans `data/trends.json`.
